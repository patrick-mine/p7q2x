Jarvis privacy policy

Jarvis is a private assistant used only by its owner. With the owner's permission it reads and changes the owner's Google Calendar and Google Tasks so it can answer the owner's own requests.

This data stays on the owner's private server. It is not shared, sold or given to anyone else, and it is not used for advertising.

The owner can remove this access at any time in the Google account settings at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
